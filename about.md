This is a game about refinement of enriched items extracted from anomaly zones (think stalker). There are many trivial items like books, gadgets, instruments, toys, plates etc. They need to be refined to extract active matter out of them. But this should be a game.

So.

Each item is going to have essences in it.

There are four types of essences - red, green, blue, yellow.

There are recipes i.e.
5 red + 10 green
9 blue + 9 red
20 blue + 10 yellow + 10 green
10 yellow + 5 red
etc.

The player makes a haul. An assortment of items is extracted. Now they need to sort them into refineries.
They choose a recipe, choose which items to refine (or click a button to do so automatically), and queue up the refinement, which takes time.
There are limited number of refinery slots, so one should choose recipes with lots of essences. But these are imballanced. Unrefined items stay until future hauls.
Refinment gives chronotraces and money.
You use money to organize a haul.
You use chronotraces to unlock better recipes.


Some recipies have special effects affecting all running processes:
Increases the refining speed by 30%
Increases the yeild by 30%
Increases the chronotrace yeild by 50% but money yeild is 0
Each green essence in the recipe speeds up the recipe by 5%
Each red essence in the recipe increases money yeild 5%
All yellow essenses obtain current green bonus effects


Global progress:
Each type of essense has "Refine 1000 essenses" progress bar, which add 5% to that essense refinement speed.


There are more types of essense that are not required by any recipe:
Magenta essense - each such essense adds 5% failure chance. Failure = no yeild.
Cyan essense - add 5% success chance. The success chance can't go over 100%.
There is a bonus effect "Success chance can go over 100%, which resuts in a chance for double yeild"
Gray - junk, it wears down the refinery. -1% refinement yeild.
Orange - oil, irestores the refinery. +1% refinement yeild if below 100%.
White - cleaning agent - restores refinery to its full yeild, but the recipe with a white essence always has 0 yeild.

Some recipes have a chance to drop one-time use recipe which gives double yeilds and requires a few magenta essenses.


Raids:
Each raid has difficulty.
Player has strength.
success chance is strength / difficulty
the first raid is 100% succcess

strength above 100% contributes to quest completion.
when completed, the player can level up and choose:
+100 bags volumes
+10 strength
+10 speed
Each next quest in the same raid requires double the points.

Chronotraces is the alternative way to upgrade strength/volume.

Each raid has duration.
Each raid has item drop chance per minute.
Each raid has a different set of items. (Only few raids drop orange essenses. The first raid doesn't drop magenta essenses at all. Some raids drop many items, but many of them are gray.)
The number of items the player can extract out of raid is limited by bags volume.

Going into raid requires strength * K amount of money. But you can go with 50% strength if you want.

Ressurection beakon - if you fail, you return with equipment and can try again.
Grenade - +10 strength
